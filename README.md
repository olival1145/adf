# Fluxo Jurídico Cloud
Frontend PWA conectado ao Supabase do projeto `fluxo-juridico-escritorio`.

- Autenticação: Supabase Auth (email/senha)
- Identidades: Olival, Érica, Dra. Kleíne via código temporário
- Banco: processos, atividades, notificações
- Filas: judicial/Olival, administrativo/Érica, correção/Dra. Kleíne
- Drive: Google OAuth Client ID configurável no app
- Realtime: atualização automática de processos e notificações
